# main 技术方案文档

## 开发分支

`main`

## 方案概览

提取接口 Apifox 网页地址解析逻辑，由接口表格名称链接和测试按钮共同复用。接口表格将解析后的地址传给测试按钮；测试结果弹框仅在地址有效时，于“关闭”按钮左侧渲染“去改 mock”链接按钮，并使用新标签页安全打开目标页面。

## 技术决策

- 直接复用表格当前的链接优先级：接口记录 `link` 优先，项目 ID 与数字接口 ID 生成的地址作为兜底。
- 跳转属于用户主动触发的外部页面打开操作，不新增网络请求、数据写入、权限、迁移或不可逆影响。
- 不通过 Mock URL 反推 Apifox 页面，避免生成不可靠地址。
- 无有效 Apifox 地址时隐藏操作，不显示点击后报错的按钮。
